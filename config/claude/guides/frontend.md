# Frontend design

Unless the task or the project's design asks for them, don't use these default styles:

- Cream or off-white backgrounds
- Italic accent words in headlines
- Numbered "01/02/03" section labels
- Monospace labels
- Pill-shaped buttons

## HTML

- Use the HTML element that fits the content: lists as lists, links to navigate, buttons to
  act, a label for every form field; generic containers only for layout.
